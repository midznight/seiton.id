## 3. Layanan dan katalog publik

Layanan baru yang telah ditambahkan ke source website:
- `setup-ai-gateway-bot`: Setup AI Gateway & Bot Asisten 24/7.
- `setup-portal-otp`: Setup Portal OTP & Email Custom Domain.

Website tidak menampilkan kredensial akun Muse Starter sebagai produk katalog publik. Harga tetap berasal dari API `https://admin.seiton.biz.id/api/pricing`; tidak ada harga fallback yang dibuat di frontend.

Snapshot read-only D1 `seiton-site-content-prod` menunjukkan tujuh layanan pada tabel `site_services`. Dua layanan baru AI Gateway dan Portal OTP memiliki record harga tetapi `available=0`; jangan menyalakan ketersediaannya sebelum scope, kesiapan backend, dan syarat pihak ketiga diverifikasi.

## 4. Hubungan dengan Worker

Repository ini memiliki:
- `workers/order-bot/README.md` dan migrasi `0002_multi_item_cart.sql`, tetapi bukan source runtime Worker order.
- `workers/site-admin/worker.js`, `wrangler.toml`, dan `migrations/0001_initial.sql`.
- Source Worker production tetap harus direkonsiliasi dengan konfigurasi Cloudflare aktual.

Catatan penting: production `seiton-site-admin` memakai service binding ke `seiton-otp-portal` dan secret internal OTP; konfigurasi source `workers/site-admin/wrangler.toml` saat ini hanya mencantumkan `SITE_DB` dan `ORDER_BACKEND`. Jangan deploy dari konfigurasi tersebut sebelum drift diselesaikan.

## 5. Persyaratan produk/operasional yang tetap berlaku

- Telegram adalah kanal transaksi utama.
- WhatsApp resmi ditunda; tidak ada aktivasi gateway WhatsApp tidak resmi.
- Harga dan katalog tidak diubah tanpa instruksi eksplisit.
- Panel UMKM yang akan dijual tidak boleh berbagi akun/data antar tenant. README Worker menyebut panel UMKM saat ini masih single-store; provisioning terpisah atau desain tenant-isolated wajib diselesaikan sebelum penjualan multi-tenant.
- Semua data demo tetap fiktif dan tidak boleh tercampur dengan transaksi production.
- Analytics hanya dimuat setelah consent eksplisit; demo tetap tanpa GTM/GA4.

## 6. Temuan dan gerbang sebelum fase berikutnya

1. Rekonsiliasi source Worker runtime dengan GitHub sebelum perubahan kode Telegram.
2. Satukan migrasi D1, termasuk `0002_multi_item_cart.sql`, ke satu repositori/source of truth.
3. Uji ulang checkout satu produk dan multi-item, verifikasi pembayaran, stok, R2 media, dan delivery digital dalam environment non-production.
4. Jangan mengaktifkan harga layanan AI Gateway/Portal OTP sampai backend dan proses fulfilment benar-benar siap.
5. Jangan membuka penjualan akun digital sampai Email Routing, portal privat, stok terenkripsi, dan alur pengiriman lulus end-to-end.
6. Update jumlah sitemap dan dokumentasi P2 setelah seluruh perubahan website disetujui.

## 7. Batas perubahan fase baseline

Audit ini hanya membaca source GitHub, metadata Cloudflare, dan schema/agregat D1. Tidak ada perubahan pada source aplikasi, harga, katalog, database, domain, consent, atau deployment production.
